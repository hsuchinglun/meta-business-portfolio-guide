# Meta 商家資產管理｜互動簡報

16 頁繁體中文簡報，以匿名案例帶你從資產盤點走到權限設定、廣告草稿測試和交接驗收。使用 Vue 3、Vite 與 [Bootstrap Icons](https://icons.getbootstrap.com/)。

## 本機預覽

使用 Node.js 22 或更新版本。

```bash
npm ci
npm run dev
```

用瀏覽器開啟終端機顯示的本機網址，通常是 `http://127.0.0.1:5173/`。

```bash
npm test
npm run export:html
```

`npm test` 會建置並測試簡報互動。`npm run export:html` 會在 `dist/preview.html` 產生可直接用瀏覽器開啟的單檔預覽。

## 簡報操作

- 用換頁按鈕、左右方向鍵或 Page Up／Page Down 換頁。點進度格或桌面左側目錄可直接跳頁。手機版的換頁列固定在頂部，投影片內文可上下滑動。按左上角標誌可回第 1 頁。
- 第 2 頁按順序比對商家編號與 IG 資產清單，第 12 頁模擬指派 IG 任務，第 14 頁用草稿循序查錯。
- 第 7–14 頁將操作、確認結果和完成標準放在同一張投影片。桌面版按視窗縮放，手機版使用較大的文字。
- 第 15 頁可直接點選常見問題查看排查方式。第 16 頁的驗收清單在每次開啟或重新整理簡報時從空白開始，換頁時保留當次勾選。

## 維護

`src/data.js` 放頁次、操作內容、排查案例、驗收項目與官方來源。`src/components/` 放互動元件，`src/style.css` 放版型與配色。

簡報內容於 2026 年 11 月 20 日核對，相關連結集中在頁首「官方來源」。實際入口、資格和可用功能依 Meta 帳號、地區及介面而異。模擬只在簡報內運作。
